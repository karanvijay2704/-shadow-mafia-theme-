# Shadow Mafia Shopify Theme

Custom Shopify Online Store 2.0 theme for **SHADOW MAFIA**.

## Direction
Dark luxury streetwear: black, deep red, white, cinematic motion and high-contrast editorial typography.

## Homepage
Announcement bar → cinematic hero → categories → featured products → brand editorial → animated campaign banner → women's spotlight → New Drop → trust strip → newsletter/footer.

## Animated video banners
Hero, Campaign video banner and New Drop support Shopify-hosted muted autoplay loops. Short 3–5 second videos are ideal. Hero and Campaign sections also support separate mobile media and fallback images.

## Native Shopify commerce
Products, variants, inventory, quantities, collections, search, cart, discounts and checkout remain native Shopify functionality.

## Release rule
This repository is the development theme. Do not publish it to the live store until the storefront preview has been approved.
